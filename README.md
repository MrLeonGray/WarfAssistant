# WarfAssistant

Десктопный помощник для **Warframe** на **WPF (.NET 9, Windows x64)** с оффлайн-базами и синхронизацией публичных API без чтения памяти игры и `EE.log`.

## Основные модули

1. **Эвенты & Мир** — таймеры открытых миров и Спирали Дувири с автопереходом фаз, недельная Цепь Инкарнонов, Вылазка, Арбитраж, Охота на Архонта, Архимедии, Календарь 1999, Почести Стального Пути, Разрывы Бездны (с fallback на DE Worldstate), Вторжения, Тревоги, Баро Ки'Тиир, Варзия (Возрождение Прайм), Ночная Волна и системные уведомления в трей Windows.
2. **Крафт & Фарм** — очередь крафта с многоуровневым разбором официальных рецептов DE (учёт выхода партий и исключение уже готовых деталей/Форм на складе), интерактивный склад ресурсов, подсказки по реликвиям и ценам WFM, расчёт оптимального маршрута фарма.
3. **Связанный Билдер** — конструктор сборок для Варфреймов, Оружия, Усилителей, Артефактов Тектолиста, Арчвинга, Компаньонов, Некрамехов и Плексуса Рэйлджека, с синергией Гельминта, Осколков Архонта, Мистификаторов, Модов Разлома, эволюций Инкарнона и расчётом DPS/TTK по модели брони **Jade Shadows**.
4. **Коллекция** — виртуальный каталог предметов Warframe из DE Public Export (`5 700+` позиций), подсчёт Ранга Мастерства, отметки наличия/ранга/Гельминта/Инкарнона, фильтрация по источникам получения и скрытие эксклюзивов Основателей.
5. **Маркет и Моды разлома** — живые ордера Warframe.Market, статистика за 48ч/90д, арбитраж Прайм-сетов и Дукат-арбитраж, калькулятор диапазонов характеристик Riven (с выбором варианта оружия и перероллами), аукционы WFM и перенос мода в Билдер.
6. **Настройки & Кэш** — профиль игрока, резервное копирование и экспорт/импорт `userdata`, управление уведомлениями и очистка дискового кэша.

## Требования

- Windows 10 / 11 (x64)
- Для запуска собранного `.exe` (`--no-self-contained`): [.NET 9.0 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/9.0)
- Для сборки из исходников: [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)

## Сборка и запуск

### Через скрипт сборки (один `.exe` в корне)
Запустите [build.bat](build.bat) или выполните в PowerShell:

```powershell
dotnet publish src\WarfAssistant.csproj -c Release -r win-x64 --no-self-contained -p:PublishSingleFile=true -p:DebugType=None -p:DebugSymbols=false -o .
```

### Отладочная сборка
```powershell
dotnet build src\WarfAssistant.csproj -c Debug
```

## Структура проекта

- `src/` — исходный код приложения (`Views`, `ViewModels`, `Services`, `Models`, `Controls`, `Styles`) и сжатые оффлайн-базы в `src/Resources/*.json.gz`
- `data/assets/` — встроенные локальные иконки
- `data/cache/` и `data/saves/` — создаются локально во время работы (исключены из Git через `.gitignore`)
- `build.bat` — скрипт публикации `WarfAssistant.exe` в Release single-file
